## 一、交付定义

实现浏览器单机动作 RPG，覆盖乌坦城到双帝之战及尾声的完整主要故事路线。使用章节式探索、即时战斗、炼药和境界成长。

“全主线”表示主要事件有开场、可操作目标、挑战、结算和后续衔接。它不表示逐字重现小说全部章节，也不表示一个章节按钮就等于该篇章完成。小说全部支线、逐集动画演出、商业级人物动画与全配音列入扩充阶段，分别追踪。

首轮全主线版本采用 28 章、程序绘制人物与场景、原创短对白。每章至少有探索采集、普通战斗、章节挑战和结算，可通关至终局；不同章节根据事件加入炼药或收服目标。

产品包含：

- 键鼠与手机横屏操作；即时移动、闪避、普攻、斗技、丹药。
- 六种环境主题及章节装饰变体，危险预警、首领阶段和可交互采集点；首轮共用碰撞地形，独立地图随后扩展。
- 角色境界、斗技解锁、火焰配置、背包、炼药、商店、同伴支援。
- 章节地图、原创开场和收尾、任务条件、可重复修炼战斗。
- 三个手动存档、自动存档、JSON 导入导出、存储失败提醒与版本校验。
- 音量、减弱动态效果、难度、剧透范围与操作说明。
- 静态构建、GitHub Actions 检查、GitHub Pages 部署工作流、运行及维护手册。

运行时不使用付费大模型服务、账号服务器或外部图像 CDN。

## 四、玩法规则

每章流程：开场对白 → 探索目标 → 采集 / 炼药 / 普通战 → 章节挑战 → 收尾 → 奖励与下一章。

战斗：

- WASD / 方向键移动，J / 鼠标主键普攻，空格闪避，1/2/3 斗技，Q 丹药，E 交互。
- 普攻无斗气消耗；斗技有斗气、冷却、攻击范围和不同反馈。
- 八极崩近身爆发；焰分噬浪尺远距前方斩击；佛怒火莲范围爆发。剧情与技能可用性由配置控制。
- 首领具有蓄力范围、阶段切换、追击、冲锋或远程弹幕；高阶战斗加强机制，避免只提高生命。
- 失焦、菜单、对白暂停；失败返回营地且保留已结算成长。
- 支援的合法状态、冷却与剧情阶段统一验证。

炼药：

- 每章可重复获得材料，失败不能永久卡主线。
- 提炼、融合、凝丹组成一次炼制；消耗与产出事务化。
- 已解锁丹方提供快捷炼制，操作版影响品质和额外产出。
- 正式状态只在结算时更新；重复事件不能多发奖励。

经济：

- 金币用于丹药、基础材料和装备强化。
- 每章首通产出由配置限定且只发一次；重复战斗与药草再生提供持续修炼来源。
- 境界与技能由剧情和修炼共同推进；重复游玩不能跳过异火取得事件。

## 五、工程方案

TypeScript、React、Vite、Phaser；规则层独立于画布，用一个权威状态驱动 UI 与战斗。

战斗逻辑固定步长，渲染帧与数值计算分离。配置包括章节、敌人、斗技、丹方、火焰与场景主题。

程序绘图资源先支撑可玩全主线，统一国风墨绿 / 古铜 / 火焰风格。后续美术替换只改变表现层与资源映射，不改任务条件。

存档：版本化 IndexedDB + 可读 JSON 备份；验证章节 ID、数量上限、非法数值、解锁一致性。优先保留现存数据，失败明确通知。用户能主动导出本地数据，默认无遥测。

测试：

- 规则单元测试：消耗、奖励幂等、技能解锁、剧透、同伴状态与迁移。
- 全剧情模拟：合法操作逐章推进，确认能到尾声且不能越章。
- 浏览器验证：新游戏、实际战斗、采集、炼药、存档、菜单与手机布局。
- CI：安装锁定依赖、类型检查、规则测试、生产构建。

## 七、完整生命周期

1. 立项：原作提纲、玩法选择、范围、资料来源。
2. 原型：移动 / 战斗 / 炼药闭环，实际试玩决定是否扩展。
3. 生产：规则数据化，全主线接入，场景与资源迭代。
4. Alpha：全主线可达、无资源死锁，存档兼容。
5. Beta：玩家试玩、不同设备验证、难度与反馈优化。
6. 发布候选：锁定依赖、检查许可与来源、构建和回滚准备。
7. 正式发布：HTTPS 静态部署、站点验收、版本记录。
8. 维护：问题分级、修复、旧档迁移、资源缓存更新、玩家反馈。
9. 内容更新：扩展支线、章节专属机制、手工关卡和人物动画。
10. 长期归档：可复现源码、锁文件、离线导出说明与最终存档格式。

## 九、发布门槛

- 能从第一章通过合法操作进入第 28 章结局。
- 存档刷新恢复，导入错误不覆盖有效状态。
- 奖励不能重复领取，材料 / 货币不能负数，剧情锁与同伴状态一致。
- 真实操作可移动、采集、炼药、战斗、重试和进入下一章。
- 锁定章节不泄露标题、描述、火焰和首领。
- 静态子路径资源正常，构建可复现，CI 配置有明确运行命令。
- 性能结果注明浏览器和设备；未执行的设备测试明确标待测。
- 文档描述当前版本，扩充需求与已完成交付分开列出。
