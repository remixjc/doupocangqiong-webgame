`pnpm build` 和 `pnpm check` 自动生成 `dist/bundle-report.json`，超预算、缺少静态模块或Phaser进入初始图会失败。`pnpm bundle:check` 复查当前dist。预算文件是本次工程回归门槛，不为隐藏变大而临时抬高；确需新资源时记录理由及新设备数据。Vite关于大包的警告保留。

当前性能证据仅含桌面浏览器正常加载、退出和再次进入时画布1→0→1。还没有长期内存曲线、真实手机帧时间、低端设备首载、网络永久挂起或浏览器失败注入结果。不得将本表标记为移动性能达标。C11b-2进一步减少暂停时绘制及重复文本更新，C11e负责真机证据。
