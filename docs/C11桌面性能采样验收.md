# C11桌面性能采样与场景装卸

2026-10-15，运行0.93.3，固定工作项E03的首份可重核桌面采样。游戏运行、剧情、存档格式和版本不变。独立工具不进入生产dist，不读取IndexedDB、游戏store或存档内容，不模拟游戏时间，不自动战斗。

## 重做方式

```bash
pnpm build
pnpm qa:desktop:check
pnpm qa:desktop
```

打开本机终端显示的`/__qa/`页面，默认4195端口；也可`pnpm qa:desktop 4196`指定另一个本地端口。服务只监听127.0.0.1，先核完整生产清单，只提供GET和固定QA入口。其他本地文件、路径越界及写入请求拒绝。三个采样页面/脚本在服务启动时固定字节和SHA256，报告同时带生产提交和工具指纹，避免测试时改脚本却沿用旧身份。

在内嵌游戏中正常开始或从游戏原生界面导入自己的合法备份；新端口是独立存档域。填写真实机器/负载说明，选10–600秒，点击开始后正常聚焦场景。不要把等待循环、规则replay或人为推进的模拟秒数填作实测。结束后点击原生“导出采样JSON”，运行：

```bash
pnpm qa:desktop:review /absolute/path/to/desktop-performance.json
```

复核器从原始帧间隔数组重算计数、累计时长、回调频率、p50/p95/p99、最大值及超20/33.33/50毫秒数量；摘要被改、原始数据缺失、非法间隔、快照时序倒退或记录了浏览器错误均拒绝。手动提前结束可保留，不冒称已达到请求时长。

## 实际环境与范围

本机系统查询：Intel NUC11PHi7，i7-1165G7，物理内存34040934400字节，Windows11专业版10.0.26300。内嵌浏览器UA为Chrome155，8逻辑线程，设备像素比2；采样中的游戏视口1265×820。机器列出多个显卡/虚拟显示适配器，实际渲染GPU未确认，不将某个型号冒签为测试GPU。其他应用存在，不是独占实验室基准。

沿上一批原件正常导入独立QA域，28章首通与早期寄售历史保持。先测180秒切换与营地运行，并12次正常往返舆图/第17或28章。每次退出都实际读到0画布，重入读到1；不是用循环计数推算实例数。该首轮保留了切换长任务与最大286毫秒的场景回调间隔。早期试用工具尚未导出原始帧间隔，首轮仅保留原生摘要/快照，不能按最终复核器重新计算原始间隔。

随后用固定指纹工具独立测180秒第28章已通关营地，正常聚焦和一次方向输入后持续运行。没有开启战斗、采集、用丹或领取奖励；这一场景不代表最重战斗场景。采样期间没有并行执行构建或测试。具体原生导出指纹、原始间隔、可重算统计、12次逐次画布读证和存档保持见`qa/c11-desktop-performance-0933.json`及同前缀采样文件。

新增三个Node验证通过，覆盖真实间隔统计、摘要/原始数据篡改拒绝，以及实际发行的只读服务、路径与GET边界；类型与生产构建通过。154个生产文件指纹与上一正式交付完全相同，旧782迁移证明保持原集合不扩大。474921/gzip163259/总JS1847247，原预算不变，运行版本仍0.93.3。新增QA只在本机独立服务使用。

- 帧时间来自浏览器实际`requestAnimationFrame`回调。报告中的每秒回调数不等于GPU实际呈现FPS；不会将约8毫秒回调直接写成游戏达到120FPS。
- 场景、菜单、无场景、失焦分组，跨组不拼接间隔；隐藏事件会清时间基线，隐藏后的首帧不把后台空档混入可见帧。
- 同一页面上下文的Long Tasks只说明超过50毫秒的主线程任务；没有调用栈或GPU时间，不能单凭条目把卡顿归因到某段引擎代码。
- 浏览器`performance.memory`可缺失、较粗，可能跨同进程页面共享。首尾或范围变化不能证明泄漏或无泄漏。本工具也会分配统计与显示对象，已计入观察开销。
- 画布移除只证明DOM回收；没有强制GC、保留路径、监听器存活或GPU资源分析，不宣称引擎所有资源已释放。
