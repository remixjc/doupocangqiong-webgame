# 程序人物与音效替换规格

2026-10-11 / 0.14.4。当前使用仓库内代码绘图和振荡器合成，没有新增外部图片、模型、音乐或在线生成服务。本表给后续素材制作提供稳定语义；资源ID目前是设计映射，尚无精灵加载器或图集导入功能。

| 资源ID | 当前实现 / 角色语义 | 替换时必须保留 |
|---|---|---|
| actor.player | draw-actor.ts，深色衣袍、背尺、玩家朝向 | 世界坐标脚下锚点、动作提示、异火颜色、受击反馈 |
| actor.npc | 事件NPC及护送实体，青灰衣袍 | 在场/书简区别，护送生命与路线 |
| actor.ally.squad / hunt / prison | 组队/猎捕/营救同伴，各自颜色与生命条 | 各自运行态和任务范围，不因换图改变AI或奖励 |
| actor.enemy.brute / hunter / mage | 普通/追踪/法术投影，颜色区分 | 生命条、蓄力目标、预警判定 |
| actor.enemy.boss | 首领1.65倍绘制，专属阶段颜色 | 招式预警、阶段和回复窗口，不覆盖地面危险范围 |
| audio.attack / skill / dodge / hurt / collect / victory | audio.ts六种合成音色 | 用户主动启用、实时主音量、0静音、暂停/后台停止 |

人物基础尺度为1；玩家1.05、常规敌人1、首领1.65、部分同伴0.95。脚下中心为世界(x,y)，影子中心(x+2,y+13×scale)。静态人物本体约宽36、高55；出招手臂和尺延伸另占范围，不是碰撞体。拟用图片时由替换层计算锚点与缩放，不能通过图片像素尺寸改动移动碰撞半径。设计图必须以游戏缩放后的实际尺寸检查轮廓、预警可见性和文字遮挡。

`ActorMotion`仅采样同一实体的世界位置与`CombatWorld.elapsed`。移动摆动随真实位移推进；站定、传送和时间回退重置。弱引用轨迹不保留已移除实体。玩家有效攻击/斗技通过现有动作成功回调提示；冷却、解锁或斗气拒绝不触发动作。死亡、受击、闪避优先于出招，敌人蓄力面向已锁定目标。暂停不使用独立真实时间继续播放。

“减弱动态效果”去掉位移摆动、人物偏移、压缩及尺挥动，保留静态出招、闪避脚下标记、受击短线、攻击范围与危险预警。后续图集必须有对应静态帧；不能把减弱动态理解为隐藏攻击或伤害信息。

动作默认图形和影子共用场景Graphics，不创建每帧精灵、计时器、DOM节点或额外画布；浮字仍使用固定30对象池。未开展真实设备帧时间/内存测量，不能据此宣称达到手机性能门槛。

替换流程：记录来源/作者/授权→增加本地资源与ID映射→设置锚点/图层/帧→保持静态帧回退→构建预算→全难度规则回放→浏览器缩放/暂停/换图检查→真机测量。声音若改用本地录音，另核对时长、响度、并发与结束释放，保留现有静音和启用门槛。素材授权缺失时继续使用当前代码资源。
