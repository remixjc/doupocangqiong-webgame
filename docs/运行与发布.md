# 运行、发布与维护

适用版本：0.1.0；更新日期：2026-10-10。

## 开发和试玩

要求 Node.js 24.19.0、pnpm 11.25.0。版本在 CI 和 package.json 中锁定。

```bash
git clone git@github.com:remixjc/doupocangqiong-webgame.git
cd doupocangqiong-webgame
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的 HTTP 地址。默认开发端口 5173；占用时以实际输出为准。

```bash
pnpm run check
pnpm build
pnpm preview
```

check 一次执行 TypeScript、Vitest 和 Vite。生产输出为 dist，可以部署到支持静态文件的主机；资源采用相对路径，支持仓库子路径。

## 基础操作与章节流程

| 输入 | 动作 |
|---|---|
| WASD / 方向键 | 移动 |
| J / 画布鼠标主键 | 普攻；J 可按住连击，鼠标点击决定攻击方向 |
| 空格 | 消耗体力闪避 |
| 1 | 八极崩，近身打断普通敌人 |
| 2 / 3 | 剧情解锁的斗技 |
| E | 采药、营地、试炼碑交互 |
| Q / F | 恢复丹 / 回气丹，共享使用间隔 |
| R | 药老支援；受剧情离队状态影响 |
| Esc | 营地 / 关闭菜单 |

每章：读开场 → 采集 / 击杀 / 指定炼药 → 右上试炼碑 → 首领 → 营地菜单结算 → 收尾 → 下一章。

手机横屏使用左侧摇杆和右侧按钮，普攻可长按。小屏竖屏暂停并显示横屏提示。菜单、对白、切后台均暂停。浏览器音效需要首次主动操作才能启动。

药草约十几秒再生；普通敌人不足可营地休整或重新进入。失败保留任务、材料和金币，角色回营地。剧情难度降低敌人生命和伤害，适合先体验主线。

## 存档和备份

IndexedDB 数据库为 doupocangqiong-saves，slots 表：

- 0：自动存档；持久化事件发生后立即开始写入。
- 1–3：手动存档。
- -1：上一份有效自动存档；与新自动存档在同一事务中更新。

存档记录章节、任务、行囊、设置与成长。战斗实时坐标和敌人不保存，载入时从营地重新开始。清除站点数据、无痕模式和更换域名会影响本地存档。开发站点与线上站点的存档相互独立，通过 JSON 备份转移。

写入和导入均校验版本、整数范围、章节顺序和解锁关系。错误导入不会替换当前状态；校验通过后仍由用户点击确认载入。自动存档损坏时尝试上一次有效备份；损坏记录不会覆盖有效恢复副本。

开始新旅程会替换自动档，手动档保留。操作前可保存到手动槽或导出 JSON。多个标签页同时游戏可能产生最后写入覆盖，建议只保留一个游戏标签。

## GitHub Pages

当前交付仅包含工作流，线上站点需要另行观察部署结果。

1. 仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
2. Actions → Publish game to Pages → Run workflow，选择 main。
3. 等待 build 与 deploy 均成功；部署地址取自工作流 Environment 输出。
4. 如需每次推送自动更新，仓库 Variables 添加 PAGES_ENABLED，值 true。

未设置变量时，推送只运行 Game checks，Pages 自动任务会跳过；手动发布仍运行完整检查。工作流使用官方 Actions，并固定到已核验提交 SHA。

## 其他静态主机与缓存

将 dist 内文件完整发布到同一目录，保留 assets 文件名。HTML 建议短缓存或 no-cache，带哈希的 assets 可长缓存。未引入 Service Worker，资源更新不需要额外清除应用缓存。

上线后检查：初始页面、首次进入画布、各按钮、子路径素材、后台恢复、保存与刷新。单独观察移动设备，不能用桌面视口模拟代替真机测试。

## 修复、迁移和回滚

1. 收集复现条件：浏览器、难度、章节、操作顺序、错误文字；个人存档仅在用户主动提供后使用。
2. 分级：数据丢失 / 无法通关最高；玩法阻断其次；表现问题按影响安排。
3. 修复规则问题并补能复现故障的测试，执行 pnpm run check。
4. 同时更新版本验收和 CHANGELOG，完成独立 Git 提交并推送。
5. 更改存档结构必须增加 schemaVersion 并提供纯函数迁移及旧档测试；不要静默重置玩家进度。
6. 发布回滚使用已验证提交构建，或通过 git revert 产生新提交，不强推主线。较旧版本拒绝较新存档时保留原文件并解释原因。

正式 Beta 前补齐：真实 iOS / Android 矩阵、普通与挑战难度完整试玩、浏览器 JSON 导出导入、键盘可达性与性能数据。进入正式发布前完成剧情来源校订、资源清单与版本冻结。

0.13.0自动存档显示读取/正在保存/已保存状态。写入未完成时等状态完成再刷新；失败在存档管理中持续显示，可重试最新内存进度或导出备份。列表读取期间显示读取提示，加载和查看会等待当前写入队列。此状态不保证强制关闭/断电可恢复，多标签覆盖防护下一批实现。
