# C11 / E03 长任务时间轴与尾队列

2026-10-15，运行版保持0.94.0。本批是独立QA证据工具修复，不新增剧情断点，不改变玩家状态或迁移集合。E03仍为部分完成，固定剩余25工作包。

## 已确认的问题

旧`qa/desktop-performance.mjs`结束时直接`disconnect()`。PerformanceObserver已经排队但尚未送达回调的条目会被丢弃，因此导出的长任务数可能漏计。以真正旧文件运行同一QA模块测试，实际调用只有`disconnect`，回归失败；当前实现先`takeRecords`再断开，同一测试通过。这个复现证明工具的收尾缺陷，不证明旧实测一定漏了某一条任务。

旧格式只保存iframe中的`startTime/duration`，没有保存父页和iframe各自的时间原点。不能直接用父页`startedAt`减iframe时间戳精确定位。旧原件保持不改，不为历史样本补造时间原点或上下文归属。

## 固定实施范围

1. 新原生导出改为QA格式2，保存两个`performance.timeOrigin`。
2. 保留浏览器实际给出的长任务`name`和`TaskAttributionTiming`的五个字符串字段。
3. 转换为采样开始后的相对起点，保留和采样窗口相交的条目；保存整条原始时长与窗口内交叠时长，不把窗口外时长混进窗口耗时。
4. 结束先收取已排队条目再断开；重复结束幂等，下一轮清空前轮观察器与记录。
5. 复核器兼容格式1；格式2从原始时间和两个原点重算，不接受篡改的起点、交叠时长或无效归属字段。拒绝非有限时长、负起点及“API不支持但有条目”。
6. 实际网页运行新工具并原生下载。报告区分API提供的浏览上下文归属和仍待的代码调用栈，不注入假长任务，不操纵游戏时间。

## 验收门槛

- 真正旧QA文件对停止队列回归失败，修复文件通过；时间原点偏移、窗口两端截断、窗口外排除、格式1只读兼容及格式2篡改拒绝有验证。
- 类型、完整测试、三难度28章回放、生产构建、固定容量与发行完整性通过。
- 155个发行文件与前正式提交清单逐项相同；src/tests/public/依赖与版本不变，847旧原件集合及已冻结迁移证明不扩大或重跑。
- 原生网页样本可由公开命令重算；构建SHA与实际工具指纹分别记录。实际持久档前后保持有原件对照。
- 更新进度/有限验收，独立提交推送，核远端SHA与匹配CI。

## 边界

`takeRecords()`只能取已排队条目。正在执行“结束”操作本身的任务尚未完成，可能之后才被浏览器报告；不承诺收齐尚未产生的未来条目。上下文归属可能只有`self/unknown`，不包含函数调用栈；它不能证实某段引擎代码、GPU或采样器自身占用了多少时间。rAF回调不是呈现FPS，粗堆与画布数仍不能代签全部资源释放。最大群战、保留对象/GPU分析和调用栈归因继续开放。
